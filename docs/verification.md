# Протокол проверки

Проверка выполнена 30 сентября 2026 года. Публичный адрес: https://integradar.org.

## Автоматические проверки

- `go test ./...` — успешно на Windows с Go 1.27.1.
- `go vet ./...` — успешно.
- `go test -race -cover ./...` — успешно в GitHub Actions на Ubuntu; результаты привязаны к коммиту в [CI](https://github.com/El1syum/tksu_pl/actions/workflows/ci.yml).
- Полный HTTP smoke-сценарий выполнен на локальном сервере и через публичный HTTPS-адрес: регистрация двух аккаунтов, вход, CRUD, фильтры, оба API статистики, CSV, изоляция аккаунтов и выход — PASS.
- Проверены повторное открытие SQLite и повторное применение миграций: расходы сохраняются, категории не дублируются.
- Проверены 20 конкурентных записей: суммы и количество совпадают, ошибок блокировки нет.
- Контейнер запускается от UID 10001, healthcheck возвращает healthy.

Покрытие прикладных пакетов на локальном прогоне: config — 90,5%; handlers — около 80%; models — 83,3%; repository — 71,3%. Покрытие не заменяет проверку сценариев и не заявляется как 100%.

## Проверенные границы

| Ситуация | Ожидаемое поведение |
| --- | --- |
| Новый аккаунт без расходов | Понятное пустое состояние, сумма 0 |
| Сумма `0`, отрицательная, `NaN`, экспонента, >2 знаков | Ошибка 422, поля сохранены |
| `0,01` и `999999999.99` | Принимаются без float-округления |
| Неверный день месяца/невисокосный 29 февраля | Ошибка даты |
| Начало периода позже конца | Ошибка 400 |
| Несуществующая категория | Ошибка формы/фильтра |
| Чужой ID при чтении, изменении, удалении | 404, данные не меняются |
| HTML/скрипт в описании | Выводится как текст |
| Отсутствующий CSRF или чужой Origin | 403 |
| Форма больше 16 KiB | 413 |
| Истёкшая/отозванная сессия | Перенаправление на вход; API 401 |
| CSV-ячейка с `=`, `+`, `-`, `@` | Начальный апостроф, формула не исполняется |
| Год без расходов | Массив 12 нулевых месяцев, пустое состояние |
| Паника обработчика | 500, следующий `/ping` отвечает |
| POST/HEAD/DELETE `/ping` без сессии | 405, заголовок `Allow: GET` |

## Браузерная проверка

В локальном тестовом аккаунте пройдены регистрация, вход, добавление расходов разных категорий и месяцев, исправление отрицательной суммы, фильтрация, статистика. Обе диаграммы построены из реально созданных записей; ошибок JS в консоли не обнаружено. Проверена навигация с клавиатуры.

Десктоп проверен при viewport 1440×900, мобильная версия — 390×844. Таблица прокручивается внутри собственного контейнера, общая страница не должна иметь горизонтальной прокрутки.
